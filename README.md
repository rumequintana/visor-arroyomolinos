# Visor urbanístico de Arroyomolinos

Consulta urbanística por parcela: ordenanza y parámetros, afecciones sectoriales, equipamientos, transporte público y ficha informativa en PDF.

**Aviso:** la información carece de valor legal y no reemplaza el contenido de los expedientes administrativos aprobados definitivamente.

Datos generados con QGIS (scripts en `01_URBANISMO/VISOR_URBANISTICO/SCRIPTS`): para actualizar, sustituir `data/datos.js`.
